# Divine - Beta

### Turn a screenshot into a starting point.

Divine transforms screenshots and design references into editable HTML and CSS layouts—right in your browser. Explore the inferred structure in a live preview, refine it visually or in code, and download a project you can keep building on.

**Private by design.** Your image is processed on your device, never uploaded. No AI services, accounts, paid APIs, or backend required.

## From image to editable layout

1. **Bring a reference** — upload or drop a PNG, JPG, JPEG, or WebP image, or try the included sample.
2. **Explore the geometry** — Divine identifies visual regions and estimates their size, position, color, alignment, and containment.
3. **Make it yours** — inspect the live preview, select and move or resize elements, and edit the generated HTML or CSS.
4. **Take it with you** — download the HTML or a complete project ZIP.

## A practical first draft

- Browser-based image analysis using deterministic visual geometry—not an AI API wrapper.
- Generated HTML and CSS designed to be readable and editable.
- Live preview that stays in sync with visual adjustments and source edits.
- PNG, JPG/JPEG, and WebP support, with images up to 25 MB and 36 megapixels.
- A lightweight, static app with no required install, account, or server.

## Built for momentum, not magic

A screenshot shows pixels, not the original source. Divine infers a plausible structure from visual boundaries; it cannot reliably recover the exact text, original DOM, or author-written CSS. Treat the result as a geometry-aware, editable starting point—not a pixel-perfect conversion.

**Divine — pixels in, possibilities out.**
